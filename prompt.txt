# 《涨停之前》新版底层 Prompt：Turboturn + 尖塔构筑版

你是我的独立游戏技术合作者。

我们正在开发《涨停之前》，一款股市主题的轻量 roguelike 连续 combo 卡牌游戏。

当前项目已经完成：

* 事件驱动内核
* EventQueue
* ComboState
* MarketPressure
* Risk 爆仓条
* Trigger-based 工具系统
* 30 张正式事件牌
* 20 个正式事件工具

但当前版本存在问题：

1. 有时会打空牌组，导致回合硬停。
2. 正式牌名不够直观，玩家看不出牌的功能。
3. 虽然有事件触发，但还不够像 Vampire Crawlers 那样高速、连续、爆发。
4. 虽然有构筑，但还不够像 Slay the Spire 那样清晰、克制、有路线压力。

新版方向：
《涨停之前》不是 5 张牌型游戏，也不是单纯事件触发器。
它应该是：
股市主题 + Turboturn 连锁出牌 + 尖塔式构筑选择 + 高速 roguelike 卡牌爽游。

核心体验：
玩家每回合面对一个 MarketPressure，相当于敌人血条。
玩家通过连续打出不同费用、不同类型的牌，触发收益、涨停、板块、抽牌、复制、止盈、杠杆、清算等事件。
牌会触发工具，工具会继续触发事件，事件推动 combo。
收益会击穿 MarketPressure。
Risk 会逼近爆仓线。
玩家要在“继续贪”和“及时止盈”之间做选择。

最重要设计目标：

1. 每张牌都要让玩家看懂“我为什么要现在打它”。
2. 每张牌名都要暗示功能，不要只有虚构公司名。
3. 每回合不允许因为牌库打空而无聊硬停。
4. 抽牌、弃牌、洗回、临时牌、结束交易必须形成完整闭环。
5. 连锁节奏要像 Turboturn：低费启动，中费放大，高费终结。
6. 构筑纪律要像 Slay the Spire：牌不是越多越好，删牌、升级、奖励取舍都重要。
7. MarketPressure 要像敌人，必须有意图、弱点和压迫感。
8. 工具要像遗物，必须改变打法，不只是加数值。
9. UI 要让玩家看懂触发链，不显示调试垃圾。
10. 不接入真实股票、真实行情、真实金融数据，不提供投资建议。

核心循环：
开盘
→ 生成 MarketPressure 和敌方意图
→ 抽初始手牌
→ 玩家用 AP / cost 连续打牌
→ 低费启动、同类触发、涨停连击、抽牌续航、复制放大
→ EventQueue 结算所有事件
→ 工具监听事件并触发
→ comboCount 和 Turboturn 阶段增长
→ 收益伤害 MarketPressure
→ Risk 增长逼近爆仓
→ 击穿 MarketPressure 后获得奖励
→ 玩家选择止盈 / 持有 / 加杠杆 / 继续交易
→ 进入下一节点或下一交易日。

新增核心规则：

1. 每张牌必须有 cost，范围 0 到 3。
2. 连续按 cost 递增打牌时，触发 Turboturn。
   例如：0 → 1 → 2 → 3。
3. Turboturn 会放大后续牌效果。
4. 抽牌、复制、返还 AP 是核心续航手段。
5. 牌库空时必须按规则洗回弃牌堆，不允许硬停。
6. 如果牌库、弃牌堆、手牌都空，则自动提供“收盘整理”或“市场噪音”兜底，不让玩家卡死。
7. 终结牌应该吃 comboCount / Turboturn 阶段 / 当前 Risk，制造爆发收束。
8. 日终奖励必须提供尖塔式选择：选牌、跳过、删牌、升级、工具、降 risk。
9. 奖励不是单纯变强，而是让玩家构筑一个明确流派。

命名规则：
卡牌名必须由“主题词 + 功能词”组成。
例如：

* 算力买入
* 涨停追击
* 融资加仓
* 止盈保险
* 低吸反弹
* 热点轮动
* 量化复制
* 连板终结
* 空头回补
* 风控重启

可以有风格化前缀，但功能词必须保留。
例如：
“星核微算”不合格。
“星核·算力买入”合格。
“赤印期服”不合格。
“赤印·杠杆终结”合格。

架构原则：

1. 核心逻辑放在 src/game/。
2. React 组件只负责 UI。
3. 不重写已通过测试的 EventQueue，除非为了修 bug 或补抽弃循环。
4. 所有随机使用 seedable RNG。
5. 每阶段必须保持 npm test 和 npm run build 通过。
6. 先修节奏和可读性，再扩内容。
7. 不做真实股票，不联网，不做多人，不做付费，不做复杂 3D 美术。

当前优先级：
第一优先级：修复打空牌组和抽弃循环。
第二优先级：加入 cost / Turboturn 递进连锁。
第三优先级：重命名正式牌，让名字直接表达功能。
第四优先级：重做奖励结构，让它更像 Slay the Spire。
第五优先级：建立清晰路线与遭遇，而不是继续堆牌。
